Uncertainty and disagreement are different

Entropy measures how spread out one model's state probabilities are. Jensen–Shannon disagreement compares aligned probability distributions across accepted random seeds. Missing seed results are never treated as agreement.

Lineage for this fit

Reproducible, with the limitations visible

Four trailing features: daily return, 30-return volatility, 30-day momentum, and volume change. Scalers fit on training data only. Expanding-window models select seeds by training likelihood. Inference uses forward filtering, never full-sequence smoothing.

Signals at close t execute at open t+1 and earn returns through open t+2. The simulator includes position drift, proportional transaction costs, and terminal liquidation. Cash earns zero. The index series omits dividends and is not an executable ETF return series.

State names are assigned from training momentum means. State matching uses a scale frozen at the first training window. Seed agreement compares initializations of one HMM, not independent model families. The historical data has already been explored; this is not an untouched holdout.

The zero-volume observation on 2023-05-24 is imputed from the previous positive volume for feature calculation only. The source CSV stays unchanged.
